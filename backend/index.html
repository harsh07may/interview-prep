How to use this page

Core · the spine, do these first Build · implement it yourself Understand · know the trade-off, reach for a library

Every topic has the same parts: what it is and why it matters, a concrete case, the core concepts, how to build it, the trade-offs, the pitfall people hit, and an exercise. Tick a topic when you have built or can explain it.

Code is pseudocode unless a snippet is labelled with a language. Real snippets are Node, with C# where a second language makes the point clearer, plus real SQL and config. Nothing here assumes a particular framework. The capstone at the end composes the exercises into one service.

That's the route. The capstone is the real test: build the order service end to end, then come back and tick the topics you had to reread.
